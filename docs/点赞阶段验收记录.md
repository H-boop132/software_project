# 点赞与取消点赞：阶段验收记录

日期：2026-10-25。开发分支：`feat/ripple-likes`。

## 本阶段成果

原来首页和详情页只能显示点赞总数。本阶段新增实际点赞、取消点赞和本人状态读取，刷新后可以恢复按钮状态。

- `PUT /api/v1/interactions/ripples/{id}/like`：设置已点赞，重复调用不会新增重复记录。
- `DELETE /api/v1/interactions/ripples/{id}/like`：取消本人点赞，重复调用不影响其他用户的点赞。
- 操作返回 `ripple_id`、`is_liked`、`like_count`，页面使用服务端确认后的结果更新。
- 时间线、详情和我的微澜响应增加 `is_liked`；列表批量读取本人状态。
- 首页和详情页复用点赞按钮，提供处理中禁用、选中样式、键盘焦点和错误后的重试。
- 写操作复用账号认证及封禁校验，只接受公开微澜。
- 复用已有 likes 表及唯一约束，无需清空或重建开发数据库。
