# 微澜 Microripple · 架构与设计说明

> 本文档说明第一版（v0.1 框架）的创意定位、数据模型与接口规划，是后续开发与演进的设计基线。

## 1. 产品创意

灵感往往稍纵即逝。「微澜」把灵感的最小单位定义为一条 **≤200 字的碎片**，并围绕碎片构建三种行为：

- **涟漪（回应）**：对碎片回应更短的衍生想法，回应可再被回应，形成波纹树；
- **潮汐（聚集）**：碎片携带话题标签，话题热度随时间自然涨落，形成动态的潮汐榜；
- **气象（共情）**：碎片可附加情绪色（喜悦/愤怒/悲伤/恐惧/思考/平静），聚合后得到全站情绪气象。

三者共同回答一个问题：*此刻，这个社区的人们在想什么、感觉如何。*

## 2. 系统架构

```
┌─────────────────┐      REST/JSON       ┌──────────────────┐
│  frontend       │ ───────────────────► │  backend         │
│  Vue3 + Vite    │ ◄─────────────────── │  FastAPI         │
│  Pinia/Router   │   JWT Bearer Token   │  SQLAlchemy 2.0  │
└─────────────────┘                      └────────┬─────────┘
                                                  │ PyMySQL
                                         ┌────────▼─────────┐
                                         │ MySQL 8          │
                                         │ 库: weilan       │
                                         └──────────────────┘
```

- 前后端完全分离，通过版本化 REST API（`/api/v1`）通信；
- 认证采用 JWT（access token），密码使用 PBKDF2-SHA256 加盐哈希存储；
- 后端按 `core / api / models / schemas / services` 分层，便于后续扩展 AI 共振等服务。

## 3. 数据模型

| 表 | 说明 | 关键字段 |
| --- | --- | --- |
| `users` | 用户 | 昵称、签名、头像、密码哈希、情绪色调偏好 |
| `ripples` | 微澜（灵感碎片） | 正文(≤200)、主话题 `topic_id`、情绪色 `emotion_code` |
| `echoes` | 回声（回应） | `root_ripple_id` + `parent_echo_id` 形成涟漪树 |
| `topics` | 话题 | 名称、slug、热度基数 |
| `emotions` | 情绪字典 | code + 中文名 + 代表色 |
| `likes` / `follows` / `collections` | 互动 | 点赞、关注、收藏（v0.2 启用接口） |

设计要点：

- 第一版微澜关联单话题、单情绪色，后续可扩展为多话题/多情绪；
- 热度 = 基础分 + 回应数×权重 + 点赞数×权重，随时间衰减（潮汐算法在 v0.2 完善）；
- 所有时间字段统一 `DATETIME` + `utf8mb4`，确保中文与 emoji 正常存储。

## 4. API 规划

| 前缀 | 模块 | 状态 |
| --- | --- | --- |
| `/api/v1/health` | 健康检查 | ✅ v0.1 |
| `/api/v1/auth/*` | 注册 / 登录 / 刷新 | ✅ v0.1（注册登录） |
| `/api/v1/users/*` | 用户信息 / 主页 / 关注 | ✅ v0.1（信息）；关注 v0.2 |
| `/api/v1/ripples/*` | 时间线 / 发布 / 详情 / 回应 | ✅ v0.1（时间线/发布/详情） |
| `/api/v1/tides/*` | 话题潮汐榜 | ✅ v0.1（聚合查询） |
| `/api/v1/moods/*` | 情绪气象 | ✅ v0.1（聚合查询） |
| `/api/v1/interactions/*` | 点赞 / 收藏 | ⏳ v0.2 |
| `/api/v1/resonance/*` | AI 语义共振 | ⏳ v0.4 |

## 5. 环境与运行

见根目录 `README.md`「快速启动」。数据库连接配置在 `backend/.env`（从 `.env.example` 复制），
默认 `weilan / root / 你的密码 / 127.0.0.1:3306`。

## 6. 演进路线

- **v0.1（当前）**：框架骨架 —— 数据库脚本、后端分层与认证、前端页面占位、接口打通；
- **v0.2**：互动闭环（点赞/收藏/关注）、回声树可视化；
- **v0.3**：个人灵感轨迹图、话题订阅；
- **v0.4**：AI 共振匹配（新灵感 ↔ 历史灵感）；
- **v0.5**：情绪气象实时大屏、消息推送。
