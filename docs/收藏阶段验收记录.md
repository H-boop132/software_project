# 收藏与取消收藏：阶段验收记录

日期：2026-10-25。开发分支：`feat/ripple-collections`。

## 本阶段成果

在已完成的点赞功能基础上，为首页卡片和详情页添加收藏入口。登录用户可以收藏、取消收藏，刷新或重新登录后读取数据库中的本人状态。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| PUT | `/api/v1/interactions/ripples/{id}/collection` | 设置已收藏，重复操作仅保留一条记录 |
| DELETE | `/api/v1/interactions/ripples/{id}/collection` | 取消本人收藏，重复操作仍为未收藏 |

接口返回 `ripple_id` 和 `is_collected`。微澜时间线、详情和我的微澜响应新增 `is_collected`；匿名请求为 false。列表批量读取状态，避免逐卡片发送请求。

收藏写操作复用现有登录与封禁校验，并与点赞共用公开内容校验及行锁。数据库继续使用现有 collections 表与唯一约束，无需执行清空建表脚本。点赞数量和状态不会随收藏操作改变。

按钮提供已收藏样式、键盘焦点、处理中禁用和错误后的重试；只在请求成功后更新页面状态。

## 验证结果

真实 MySQL 集成测试共 17 项通过，其中新增收藏测试 9 项，原有点赞回归测试 8 项。两组测试分别创建随机名称的临时数据库，使用项目建表脚本，结束后自动清理。

| 收藏用例 | 结果 |
| --- | --- |
| 重复收藏仅一条记录，重新读取详情保持状态 | 通过 |
| 重复取消不修改其他用户记录 | 通过 |
| 匿名、本人、其他账号在列表和详情中状态正确 | 通过 |
| 未登录返回 401，封禁用户返回 403 | 通过 |
| 到期封禁继续使用原有自动解封规则 | 通过 |
| 下架、待审核和不存在的内容拒绝收藏与取消操作 | 通过 |
| 非法、零和负数 ID 返回 422 | 通过 |
| 8 个并发收藏或取消请求保持幂等 | 通过 |
| 收藏与点赞状态及计数互相独立 | 通过 |

前端 Vite 生产构建通过，仍有项目原有包体积提示。

从项目根目录复现测试（PowerShell，需已配置 backend/.env）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-dev.txt
Set-Location backend
$env:WEILAN_MYSQL_TESTS = '1'
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
Remove-Item Env:\WEILAN_MYSQL_TESTS
```

## 页面验收

使用演示账号 demo 完成以下操作：

1. 在首页收藏第一条微澜，按钮变为“已收藏”。
2. 刷新首页，仍为“已收藏”。
3. 从首页进入详情，收藏状态一致，点赞数仍为 2。
4. 在详情页取消收藏，按钮恢复“收藏”，点赞状态与数量保持原样。
